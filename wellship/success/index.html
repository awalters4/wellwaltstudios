You're in. Check your email.

A GitHub invite to the private WellShip repo is on its way — usually arrives within a few minutes. Here's what to do when it lands.

1

Accept the GitHub invite

Check your email for an invitation from GitHub, or go to github.com/notifications and accept it there.

2

Clone the repo and install

Once you have access, clone and run npm install. Everything from there is in docs/SETUP.md.

3

Follow SETUP.md — 14 steps to first device build

Copy .env.example to .env, fill in your Supabase, RevenueCat, PostHog, and Sentry keys, then npx expo start.

after accepting the invite
$ git clone https://github.com/awalters4/wellship your-app
$ cd your-app && npm install
$ cp .env.example .env   # every key documented in SETUP.md
$ npx expo start
✓ auth, paywall, analytics, and crash reporting running on device
